# TAN Intelligence

Corporate landing page for **TAN Intelligence** — Powering the Future with Autonomous AI Systems.

## Local preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

1. Push this repository to GitHub.
2. Settings → Pages → Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Site will be live at `https://<your-username>.github.io/tan-intelligence/`
